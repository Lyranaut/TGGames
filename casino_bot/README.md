# Казино-бот для Telegram (aiogram 3)

Блэкджек, рулетка, быстрый покер (видеопокер) и слоты — с общей экономикой
фишек на весь бот. Регистрация не нужна: баланс выдаётся автоматически при
первом обращении.

## 1. Установка

```bash
python -m venv venv
venv\Scripts\activate        # Windows
# source venv/bin/activate   # Linux/Mac

pip install -r requirements.txt
```

## 2. Токен бота

Впишите токен в `config.py` вместо `"ВАШ_ТОКЕН_СЮДА"`, либо задайте через
переменную окружения `BOT_TOKEN`.

## 3. Добавление бота в чат

1. Добавьте бота в вашу группу.
2. У BotFather выполните `/setprivacy` → выберите бота → **Disable** —
   обязательно для рулетки (`/bet` в общем чате).
3. Регистрация в личке боту **не нужна** — все игры играются прямо в
   группе, баланс выдаётся автоматически.

## 4. Запуск

```bash
python bot.py
```

## 5. Список команд

Список также доступен в чате командой `/help`.

| Команда | Что делает |
|---|---|
| `/blackjack СТАВКА` | 🃏 Блэкджек против дилера |
| `/roulette` | 🎡 Открыть раунд рулетки (приём ставок 30 сек) |
| `/bet ТИП СУММА` | Поставить в открытом раунде рулетки |
| `/poker СТАВКА` | 🃏 Быстрый покер (видеопокер, Jacks or Better) |
| `/slots СТАВКА` | 🎰 Слоты |
| `/balance` | 💰 Проверить свой баланс |
| `/give @username СУММА` | 👑 Начислить фишки игроку (только админы чата) |
| `/give все СУММА` | 👑 Начислить фишки всем, кто уже писал в чате (только админы) |
| `/help` | Список игр и команд |

## 6. Правила игр

### 🃏 Блэкджек
`/blackjack 100` — ставка списывается сразу. Раздаются 2 карты вам и 2
дилеру (одна закрыта). Кнопки «Ещё карту» / «Хватит». Дилер добирает до
17+. Блэкджек с первых двух карт — выплата 3:2, обычный выигрыш — 1:1,
ничья — ставка возвращается.

### 🎡 Рулетка
`/roulette` открывает приём ставок на `ROULETTE_BET_TIME` секунд для всех
в чате. Ставить — командой `/bet ТИП СУММА`:
- число 0-36 — выплата 35:1
- `красное` / `черное` — 1:1
- `чет` / `нечет` — 1:1
- `меньше` (1-18) / `больше` (19-36) — 1:1

Зеро (0) — все внешние ставки (цвет/чёт-нечет/половина) проигрывают,
выигрывает только прямая ставка на 0.

### 🃏 Быстрый покер (видеопокер, Jacks or Better)
`/poker 50` — раздаются 5 карт. Нажимайте на карты, чтобы «придержать»
(🔒), затем «Раздать» — карты без замка заменятся новыми. Выплата по
таблице (множитель × ставка):

| Комбинация | Множитель |
|---|---|
| Роял-флэш | ×800 |
| Стрит-флэш | ×50 |
| Каре | ×25 |
| Фулл-хаус | ×9 |
| Флэш | ×6 |
| Стрит | ×4 |
| Тройка | ×3 |
| Две пары | ×2 |
| Пара валетов и старше | ×1 |

*(Это адаптация под текст-бота — не полноценный Texas Hold'em с торгами
между игроками, а быстрый одиночный раунд видеопокера. Если имелась в
виду именно многопользовательская игра с торгами — напишите, это отдельная
и значительно более объёмная механика.)*

### 🎰 Слоты
`/slots 50` — три барабана, мгновенный результат. Три одинаковых символа —
крупная выплата (от ×8 до ×77 в зависимости от символа), два одинаковых —
×2, иначе ставка сгорает.

## 7. Экономика и админ-команды

- Баланс выдаётся автоматически (`STARTING_BALANCE` в `config.py`) при
  первом обращении к `/balance` или любой игре — регистрироваться не
  нужно.
- `/give @username 500` и `/give все 500` доступны только тем, кто
  является администратором чата (бот проверяет это через Telegram API
  при каждом вызове команды).
- **Важное ограничение Telegram Bot API**: у ботов нет способа получить
  полный список участников чата напрямую. Поэтому `/give все` начисляет
  фишки только тем, кого бот уже «видел» — то есть кто хотя бы раз написал
  что-нибудь в этом чате. То же самое и с `/give @username` — бот должен
  был хотя бы раз увидеть сообщение от этого пользователя (в любом чате,
  где есть бот), чтобы связать его username с id.

## 8. Структура проекта

```
casino_bot/
  bot.py                    — точка входа
  config.py                 — токен, минимальные ставки, стартовый баланс
  balances.json               — создаётся автоматически, баланс фишек по user_id
  users_registry.json           — создаётся автоматически, username->id и участники чатов
  core/
    economy.py                  — баланс фишек, списание/начисление, проверка ставки
    users_registry.py             — резолвинг @username и списка «все»
    tracking.py                     — middleware, запоминающее пользователей
    admin.py                          — /give, /balance
    help.py                            — /help, /start в группе
    cards.py                            — общая колода для блэкджека и покера
  games/
    blackjack.py
    roulette.py
    fastpoker.py
    slots.py
```

## 9. Идеи на будущее

Что ещё хорошо ложится на казино-бота в Telegram-чате, если захотите
расширяться:

- **Краш (Crash)** — множитель растёт в реальном времени у всех на
  глазах, каждый жмёт «Забрать» когда хочет — отлично работает именно в
  групповом формате, азартно и наглядно.
- **Кости / Сик-Бо** — простая RNG-игра на сумму/чёт-нечет выпавших
  костей, минимум кода.
- **Кено** — выбираете несколько чисел, бот вытягивает случайные,
  выплата по числу совпадений.

## 10. Важные технические детали (на будущее, если будете дорабатывать)

- Блэкджек и покер — одиночные игры, ключ `(chat_id, user_id)`, поэтому
  несколько игроков могут играть параллельно в одном чате без конфликтов.
- Рулетка — раунд один на чат/ветку (`(chat_id, thread_id)`), пока раунд
  открыт, повторный `/roulette` в той же ветке откажет.
- Никакого общего реестра «одна игра на чат» (как в других наших ботах)
  здесь нет и не нужен — казино-игры не мешают друг другу, а рулетка сама
  следит за своим состоянием.
- Все данные (балансы, реестр пользователей) — на диске в JSON, переживают
  перезапуск бота (в отличие от текущих партий — они, как обычно, только
  в памяти процесса).
