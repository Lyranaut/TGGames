# Бункер-бот для Telegram (aiogram 3)

Бот для игры в «Бункер» прямо в вашем групповом чате (в том числе в
отдельной ветке / теме форума). Регистрация по кнопке → раздача карточек
персонажа в ЛС → раунды раскрытия карт с обсуждением и голосованием на
исключение → пока в живых не останется ровно столько человек, сколько
вмещает бункер.

## 1. Установка

```bash
python -m venv venv
venv\Scripts\activate        # Windows
# source venv/bin/activate   # Linux/Mac

pip install -r requirements.txt
```

## 2. Токен бота

Токен уже вписан в `config.py` (бот `@BunkerGloryPon_bot`). Если захотите
поменять — либо впишите новый прямо в `config.py`, либо задайте через
переменную окружения `BOT_TOKEN`.

## 3. Добавление бота в чат

1. Добавьте `@BunkerGloryPon_bot` в вашу группу (для игры в отдельной ветке
   у группы должны быть включены "Темы"/Topics).
2. **Дайте боту права администратора** с разрешением **"Удаление сообщений"**
   — во время чьего-то хода на выступлении бот тихо удаляет сообщения всех
   остальных участников, без предупреждений. Без этого права удаление
   просто не сработает.
3. Каждый участник должен **лично** написать боту `/start` в личные
   сообщения — иначе Telegram не позволит боту прислать ему карточки.

## 4. Запуск

```bash
python bot.py
```

## 5. Как играть

В нужном чате (в нужной ветке) отправьте:

```
/bunker
```

Появятся кнопки:
- **✅ Вступить** — присоединиться к игре;
- **▶️ Начать игру** — начать (доступно только тому, кто вызвал `/bunker`);
- **🚫 Отменить** — отменить регистрацию.

После «Начать»:
1. Бот проверяет, что все вступившие писали ему `/start`.
2. Случайно выбираются **катастрофа** и **описание бункера**, объявляются
   в чат вместе с вместимостью бункера (сколько человек из всех выживет).
3. Каждому в ЛС уходит полный набор карточек персонажа: пол, возраст,
   профессия, здоровье, хобби, фобия, черта характера, багаж, доп. факт,
   особое условие.
4. Начинается **раунд 1**: по очереди каждый живой игрок получает слово
   (1 сообщение, ограничение по времени) — во время его речи сообщения
   остальных участников тихо удаляются. В этом раунде нужно раскрыть пол,
   возраст и профессию.
5. После круга выступлений — свободное обсуждение, затем голосование:
   кого не пустить в бункер. У кого больше голосов — выбывает, его
   карточки показываются всем.
6. Раунды повторяются, каждый раз открывая новые характеристики (здоровье
   + хобби → фобия + черта характера → багаж + доп. факт → особое
   условие), пока не закончатся карты — дальше раунды идут без новых
   карт, только обсуждение и голосование.
7. Игра заканчивается, когда живых игроков становится ровно столько,
   сколько вмещает бункер — все выжившие объявляются победителями.

## 6. Настройка

Все параметры — в `config.py`:

- `MIN_PLAYERS` — минимум игроков для старта;
- `SPEECH_TIME`, `DISCUSSION_TIME`, `VOTE_TIME` — таймеры в секундах;
- `BUNKER_CAPACITY_RATIO` — доля игроков, которая попадёт в бункер
  (по умолчанию 0.5, то есть примерно половина);
- `MIN_CAPACITY` — минимальная вместимость бункера, даже при маленьком
  числе игроков.

Порядок раскрытия карточек по раундам — в `game/cards.py`, переменная
`ROUND_CATEGORIES`. Сам контент карточек (профессии, здоровье, фобии и
т.д.) — там же, в виде обычных списков; можно свободно добавлять свои
варианты или убирать существующие.

## 7. Структура проекта

```
bunker_bot/
  bot.py               — точка входа
  config.py            — токен, таймеры, вместимость бункера
  known_users.json      — создаётся автоматически, кто писал боту в ЛС
  game/
    models.py           — Player, Game, GameState
    cards.py              — весь контент карточек + логика раздачи и раундов
    manager.py              — хранилище активных игр (по chat_id + thread_id)
  handlers/
    common.py             — обработка /start в личке
    registration.py        — /bunker, кнопки Вступить/Начать/Отменить
    round.py                 — раунды: выступления, обсуждение, голосование
```

## 8. Отличия и упрощения по сравнению с «настольным» Бункером

- Вместимость бункера считается по формуле от числа игроков
  (`BUNKER_CAPACITY_RATIO`), а не привязана механически к описанию бункера
  (описание — художественный текст для атмосферы);
- при ничьей на голосовании исключается случайный игрок из лидеров
  голосования — чтобы игра гарантированно продвигалась дальше;
- «особое условие» — карточка для атмосферы и отыгрыша, бот не проверяет
  и не применяет её эффект механически (например, «право вето» нужно
  использовать по-честному, на словах, в чате);
- если игроков больше 16–20, карточки в редких категориях (особое
  условие) могут повториться у разных игроков — соответствующие списки
  можно расширить в `game/cards.py`.
