# Бот Бога Настолок для Telegram (aiogram 3)

Один бот, шесть игр в вашем групповом чате (в том числе в отдельной ветке /
теме форума): Крокодил, Виселица, Кто я?, Элиас 2 на 2, «Придумай смешнее»
(в духе Jackbox Party Pack) и Викторина.

## 1. Установка

```bash
python -m venv venv
venv\Scripts\activate        # Windows
# source venv/bin/activate   # Linux/Mac

pip install -r requirements.txt
```

## 2. Токен бота

Токен уже вписан в `config.py` (бот `@TableGloryPon_bot`). Чтобы поменять —
впишите новый прямо в `config.py` вместо текущего значения, либо задайте
через переменную окружения `BOT_TOKEN`.

## 3. Добавление бота в чат

1. Добавьте `@TableGloryPon_bot` в вашу группу (для игры в отдельной ветке
   у группы должны быть включены «Темы»/Topics).
2. У BotFather выполните `/setprivacy` → выберите бота → **Disable** —
   обязательно, иначе бот не увидит обычные сообщения в чате (а на них
   держится половина игр: отгадки в Крокодиле, буквы в Виселице, ответы в
   Викторине).
3. Для игр с личными сообщениями (Крокодил, Кто я?, Элиас, «Придумай
   смешнее») каждый участник должен **лично** написать боту `/start` —
   иначе Telegram не даст боту написать ему первым.

## 4. Запуск

```bash
python bot.py
```

## 5. Список команд

Список также доступен в чате командой `/help`.

| Команда | Игра |
|---|---|
| `/crocodile` | 🐊 Крокодил |
| `/hangman` (`/hangman_stop`) | 🎯 Виселица |
| `/whoami` (`/answer <ответ>`, `/whoami_stop`) | 🎭 Кто я? |
| `/elias` | 🗣 Элиас 2 на 2 |
| `/funprompt` | 😂 Придумай смешнее |
| `/quiz` | 🧠 Викторина |
| `/help` | Список игр и команд |

**Важно:** в одном чате (ветке) одновременно может идти только одна игра —
следующая команда откажет, пока текущая не закончится или её не отменят.

## 6. Правила игр

### 🐊 Крокодил
Регистрация кнопками «Вступить» → «Начать» (нужно минимум
`CROCODILE_MIN_PLAYERS` игроков). По очереди каждый становится ведущим:
получает слово в личку и объясняет его в общем чате словами, не называя
само слово и однокоренные (если назовёт — сообщение удаляется и приходит
предупреждение). Бот сам ловит первое сообщение с верным словом от любого
не-ведущего — очко получают и угадавший, и ведущий. На каждого ведущего
даётся `CROCODILE_ROUND_TIME` секунд, после чего слово раскрывается и ход
переходит к следующему. После того как все побывали ведущими — итоговый
счёт.

### 🎯 Виселица
Открытая игра без регистрации — участвует весь чат. Бот загадывает слово,
показывает число букв и ASCII-рисунок виселицы. Пишите в чат одну букву
или слово целиком; неверные буквы добавляют часть к рисунку виселицы
(всего `HANGMAN_MAX_WRONG` попыток). `/hangman_stop` — остановить и
раскрыть слово досрочно.

### 🎭 Кто я?
Регистрация кнопками (минимум `WHOAMI_MIN_PLAYERS` игроков). Каждому
достаётся случайная тайная личность — её видят все остальные игроки (в
личке при старте), кроме самого игрока. В общем чате задавайте вопросы
да/нет и пытайтесь понять, кто вы. Когда думаете, что знаете ответ —
пишите в чат `/answer ваш ответ` (сравнение без учёта регистра и
пунктуации, но по смыслу должно быть довольно точным). Игра продолжается,
пока все не отгадают, либо пока хост не остановит её командой
`/whoami_stop` — тогда все оставшиеся личности раскрываются.

### 🗣 Элиас 2 на 2 (командный Крокодил словами)
Регистрация кнопками — нужно **ровно 4** игрока, команды по 2 составляются
случайно. Игра идёт заходами по `ELIAS_ROUND_TIME` секунд: один игрок
команды объясняет слова в чат (без однокоренных), напарник отгадывает —
бот сам засчитывает верные ответы и сразу выдаёт следующее слово, пока не
кончится время захода. Всего `ELIAS_ROUNDS_PER_TEAM` × 2 захода (команды
чередуются, а внутри команды чередуется, кто объясняет). Побеждает команда
с большим числом верных слов.

### 😂 Придумай смешнее
*(лучшее совпадение с описанной вами игрой из Jackbox Party Pack, которое
удалось однозначно реализовать текстом в Telegram — по сути это игра в
духе Quiplash/Fibbage: заполни пропуск смешным ответом, потом голосование
за самый смешной вариант. Если имелась в виду другая конкретная игра —
опишите её механику, и я адаптирую.)*

Регистрация кнопками (минимум `FUNPROMPT_MIN_PLAYERS` игроков). Каждый
раунд бот присылает всем одну и ту же фразу с пропуском — например,
«Худший подарок на день рождения: ___». У вас `FUNPROMPT_SUBMIT_TIME`
секунд, чтобы прислать свой вариант **в личку** боту. Дальше все ответы
показываются в чате анонимно и в случайном порядке — голосуйте кнопками
за самый смешной чужой вариант (`FUNPROMPT_VOTE_TIME` секунд, за свой
вариант голосовать нельзя). Автору варианта с наибольшим числом голосов —
столько же очков. Всего `FUNPROMPT_ROUNDS` раундов, в конце — таблица
очков.

### 🧠 Викторина (добавлено от себя)
Регистрация кнопками (минимум `QUIZ_MIN_PLAYERS` игроков, но фактически
отвечать может кто угодно в чате — присоединится автоматически при первом
верном ответе). Бот задаёт вопрос, у всех `QUIZ_QUESTION_TIME` секунд —
кто первым напишет верный ответ в чат, получает очко. Всего `QUIZ_ROUNDS`
вопросов, в конце — таблица очков.

## 7. Настройка

Все параметры (минимум игроков, таймеры, число раундов) — в `config.py`.
Контент (слова для Крокодила/Элиаса, слова для Виселицы, личности для
«Кто я?», вопросы Викторины, фразы для «Придумай смешнее») — в
`core/wordbank.py` и `core/content.py`, можно свободно дополнять.

## 8. Структура проекта

```
table_bot/
  bot.py                 — точка входа
  config.py              — токен, таймеры, минимумы игроков
  known_users.json         — создаётся автоматически, кто писал боту в ЛС
  core/
    common.py               — обработка /start в личке
    help.py                   — /help и /start в группе
    registry.py                 — общий реестр «в чате уже идёт другая игра»
    utils.py                     — определение реальной ветки форума, сравнение текста
    wordbank.py                    — слова для Крокодила/Элиаса/Виселицы
    content.py                       — личности «Кто я?», вопросы Викторины, фразы джекбокс-игры
  games/
    crocodile.py
    hangman.py
    whoami.py
    elias.py
    funprompt.py
    quiz.py
```

## 9. Важные технические детали (на будущее, если будете дорабатывать)

- **Все 4 игры, слушающие обычные сообщения в чате** (Крокодил, Виселица,
  Элиас, Викторина), используют общий паттерн: `raise SkipHandler`, когда
  сообщение не относится к их активной игре. Это критично для aiogram —
  без этого первый по порядку регистрации роутер перехватывал бы вообще
  все сообщения в группе, даже когда играет кто-то другой. Если будете
  добавлять новую игру с похожим слушателем — обязательно сохраните этот
  паттерн (см. `games/quiz.py::on_group_message` как образец).
- Один активный «слот» на чат/ветку на все игры разом — через
  `core/registry.py`. Не создавайте вторую игру той же или другой командой,
  пока `registry.is_busy(...)` не освобождён (`registry.release(...)`
  вызывается при завершении/отмене каждой игры).
- Всё хранится в памяти процесса — при перезапуске бота активные игры
  и очки текущей партии теряются (`known_users.json` — исключение, он на
  диске).
