# Мафия-бот для Telegram (aiogram 3)

Бот для игры в Мафию прямо в вашем групповом чате (в том числе в отдельной
ветке / теме форума). Регистрация по кнопке → раздача ролей в ЛС → ночные
действия (мафия/доктор/комиссар) → день с очередью выступлений, свободным
обсуждением и голосованием.

## 1. Установка

```bash
python -m venv venv
venv\Scripts\activate        # Windows
# source venv/bin/activate   # Linux/Mac

pip install -r requirements.txt
```

## 2. Токен бота

1. Напишите **@BotFather** в Telegram → `/newbot` → получите токен.
2. У BotFather выполните `/setprivacy` → выберите бота → **Disable**.
   Это обязательно: без этого бот не видит обычные сообщения в группе
   (нужно, чтобы отслеживать очередь выступлений и т.д.).
3. Задайте токен одним из способов:
   - переменная окружения: `set BOT_TOKEN=123456:AA... ` (Windows) /
     `export BOT_TOKEN=123456:AA...` (Linux/Mac), либо
   - впишите прямо в `config.py` вместо `"ВАШ_ТОКЕН_СЮДА"`.

## 3. Добавление бота в чат

1. Добавьте бота в вашу супергруппу (обычную группу нужно сначала
   преобразовать в супергруппу — например, включив "Темы"/Topics в
   настройках группы, если хотите играть в отдельной ветке).
2. **Дайте боту права администратора** с разрешением **"Удаление сообщений"**
   (Delete messages) — это обязательно: во время чьего-то хода на
   выступлении бот тихо удаляет сообщения всех остальных участников, без
   предупреждений. Без этого права удаление просто не сработает (бот
   промолчит и оставит сообщение, ошибки не будет — но защита от
   "перебивания" работать не будет).
3. Каждый участник, который хочет играть, должен **лично** написать боту
   `/start` в личные сообщения — иначе Telegram не позволит боту прислать
   ему роль (это ограничение самого Telegram, не бота).

## 4. Запуск

```bash
python bot.py
```

## 5. Как играть

В нужном чате (в нужной ветке, если это тема форума) отправьте:

```
/mafia
```

Бот попросит того, кто вызвал `/mafia`, написать роли для игры и их
количество, например:

```
мафия 2 доктор 1 комиссар 1 маньяк 1
```

Доступные роли: мафия, дон, доктор, комиссар, путана, маньяк, двуликий.
Всем, кому не хватило явной роли, автоматически достаётся мирный житель.

После этого появится сообщение с кнопками:
- **✅ Вступить** — присоединиться к игре (жмут все желающие игроки);
- **▶️ Начать игру** — начать (доступно только тому, кто вызвал `/mafia`);
- **🚫 Отменить** — отменить регистрацию.

После нажатия «Начать»:
1. Бот проверяет, что все вступившие писали ему `/start` в личку.
2. Каждому участнику присваивается роль и отправляется в ЛС.
3. Наступает **ночь**: мафия, доктор и комиссар получают в ЛС список
   живых игроков с номерами/кнопками и выбирают действие в течение
   `NIGHT_ACTION_TIMEOUT` секунд.
4. Наступает **день**:
   - по очереди каждый живой игрок получает слово (1 ход, ограничение
     по времени `DAY_SPEECH_TIME`). Пока говорит один игрок, сообщения
     всех остальных участников **тихо удаляются ботом**, без каких-либо
     предупреждений (требует прав администратора «Удаление сообщений» —
     см. пункт 3 раздела "Добавление бота в чат");
   - затем свободное обсуждение `DAY_FREE_DISCUSSION_TIME` секунд;
   - затем голосование кнопками `DAY_VOTE_TIME` секунд — у кого больше
     голосов, тот выбывает (при равенстве — никто не выбывает).
5. Цикл ночь/день повторяется, пока не выполнится условие победы:
   - мафии (и маньяка) не осталось → **победа мирных**;
   - мафия составляет большинство среди живых → **победа мафии**;
   - маньяк остался единственным живым игроком → **победа маньяка**.

## 5.1 Роли

| Роль | Что делает |
|---|---|
| 🔪 Мафия | Голосует ночью, кого убить (вместе с доном) |
| 🎩 Дон | Глава мафии, тоже голосует за убийство. При проверке комиссаром получает ложный результат «не мафия» |
| 💉 Доктор | Лечит одного игрока за ночь — спасает от удара и мафии, и маньяка |
| 🕵️ Комиссар | Проверяет одного игрока за ночь — мафия ли он (дон и двуликий обманывают проверку) |
| 💋 Путана | «Навещает» одного игрока за ночь — его действие в эту ночь не срабатывает (лечение/проверка/голос мафии/удар маньяка) |
| 🔦 Маньяк | Независимый убийца, играет один против всех, ночью выбирает жертву сам |
| 🎭 Двуликий | Обычный мирный без ночных действий, но при проверке комиссаром ложно светится мафией |
| 👤 Мирный житель | Без ночных действий |

**Важное упрощение**: проверка комиссара показывается ему сразу во всплывающем
окне в момент выбора цели. Из-за этого путана технически не может "стереть"
уже показанный комиссару результат, даже если навестит именно его этой же
ночью — эффект блокировки в этом случае не влияет на уже увиденную
информацию (только на дальнейшую механику). Это сознательное упрощение ради
простоты кода.

## 6. Настройка

Все параметры — в `config.py`:

- `MIN_PLAYERS` — минимум игроков для старта игры (реальный минимум для
  конкретной катки — не меньше суммы ролей, заказанных хостом);
- набор ролей задаётся хостом при создании катки текстовым сообщением и
  разбирается в `game/roles.py::parse_role_counts`; мирные жители
  добавляются автоматически на оставшиеся места (`assign_roles`);
- `NIGHT_ACTION_TIMEOUT`, `DAY_SPEECH_TIME`, `DAY_FREE_DISCUSSION_TIME`,
  `DAY_VOTE_TIME` — все таймеры в секундах.

## 7. Структура проекта

```
mafia_bot/
  bot.py               — точка входа
  config.py            — токен, таймеры, таблица ролей
  known_users.json      — создаётся автоматически, список тех, кто писал боту в ЛС
  game/
    models.py           — Player, Game, Role, GameState
    roles.py             — распределение ролей
    manager.py            — хранилище активных игр (по chat_id + thread_id)
  handlers/
    common.py             — обработка /start в личке
    registration.py        — /mafia, кнопки Вступить/Начать/Отменить
    night.py                — ночные действия и разрешение ночи
    day.py                   — очередь выступлений, обсуждение, голосование
```

## 8. Что можно доработать дальше

- Хранение состояния игр в БД (сейчас всё в памяти — при перезапуске бота
  активные игры теряются);
- Более сложные роли (маньяк, шериф с разными способностями, любовники и т.д.);
- Возможность голосования "поднять руку, чтобы говорить вне очереди";
- Ограничение: сейчас у мафии нет общего чата для согласования цели —
  каждый мафиози голосует независимо, побеждает большинство (при ничьей —
  случайный из лидеров). При желании можно сделать общий "виртуальный"
  чат мафии через пересылку сообщений между мафиози ботом.
